# X Tweaks（Chromium拡張機能）

Xを使いやすくするための拡張機能です。

## インストール・更新
1. ZIPを展開する（更新のときは前のフォルダに上書きでOK）
2. Chrome / Edge / Brave で `chrome://extensions` を開き、「デベロッパーモード」をオンにする
3. 初回は「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選ぶ。更新のときは拡張機能の更新ボタンを押す
4. x.com のタブを再読み込みする

設定はツールバーの鳥アイコンから変更できます。

## できること（v0.3）
- **fxtwitterコピー**：ツイート下の共有ボタンが、`https://fxtwitter.com/ユーザー/status/ID` をコピーするボタンになります。コピーできるとアイコンが一瞬緑のチェックになります。
- **サイドバー整理**：設定画面でチェックした左サイドバーの項目を隠します。
- **1回でリツイート**：リツイートボタンを押すと、メニューで自動的に「リポスト」を選びます。取り消しは今まで通り確認メニューが出ます。
- **メディア（すべて）タブ**：プロフィールのタブ列の最後に追加されます。押すと、画像と動画をまとめた検索結果（`from:ユーザー filter:media`）を開きます。

## 注意
- 「メディア（すべて）」は検索結果を使うため、センシティブ設定のある投稿や一部の古い投稿が出ないことがあります。
- Xが画面の作りを変えると動かなくなることがあります。

## フォルダ構成
- `src/content/settings.js` 設定の既定値と読み書き
- `src/content/sidebar-items.js` 隠せるサイドバー項目の一覧
- `src/content/core.js` 機能の登録とDOM監視（各機能は `TR.register` で追加）
- `src/features/` 機能ごとのファイル
- `src/options/` 設定画面
