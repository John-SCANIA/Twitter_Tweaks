# Twitter Tweaks（Chromium拡張機能）

Xを使いやすくするための拡張機能です。

## INSTALL
1. Chrome / Brave 等のchromium系のブラウザで `chrome://extensions`を開き "デベロッパーモード"を有効にする。
2. "パッケージ化"されていない拡張機能を読み込む"から解凍したファイルを選択する。
3. X.com を再読み込みする。
    設定はツールバーの鳥アイコンから変更できます。

## できること（v0.3）
- **リンク共有のボタン** : ツイート右下の共有ボタンが、`https://fxtwitter.com/"userid"/status/` をコピーするボタンになります。
- **サイドバー整理** : 設定画面でチェックした左サイドバーの項目を隠します。
- **1回でリツイート** : リツイートボタンを押すと、メニューで自動的に"リツイート"を選びます。取り消しは今まで通り確認メニューが出ます。
- **メディア（動画・画像）を同時に表示** : メディア(すべて) を押すと、画像と動画をまとめた検索結果（`from:ユーザー filter:media`）を開きます。

## 注意
- 「メディア（すべて）」は検索結果を使うため、センシティブ設定のある投稿や一部の古い投稿が出ないことがあります。
- Xが画面の作りを変えやがると動かなくなることがあります。

## フォルダ構成
- `src/content/settings.js` 設定の既定値と読み書き
- `src/content/sidebar-items.js` 隠せるサイドバー項目の一覧
- `src/content/core.js` 機能の登録とDOM監視（各機能は `TR.register` で追加）
- `src/features/` 機能ごとのファイル
- `src/options/` 設定画面


この拡張機能はClaude Opus 5.5が作りました。
